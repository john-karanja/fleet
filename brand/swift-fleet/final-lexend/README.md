# Swiftfleet logo kit: Lexend version (2 Oct 2026)

An alternative kit kept alongside the family version in `../final/`. **Nothing in `../final/` was
replaced.**

- **Design:** Lexend ExtraBold (the app's interface font), slanted 12°, with the i-dot as a teal
  dash trailing back.
- **Spacing:** tracking −24, with the f→t, t→f and f→l pairs opened.
- **App icon:** the slanted s with the trailing dash.

**Two colour schemes:**
- **A:** all navy, teal dash only. The most distinctive.
- **B:** "swift" navy, "fleet" teal, like the Swiftcent parent. Own voice plus family colours.

| File | Use |
|---|---|
| `A-wordmark-light/dark.svg`, `B-wordmark-light/dark.svg` | Main logo, scheme A or B |
| `wordmark-mono-navy.svg`, `wordmark-mono-white.svg` | One colour ("Powered by" inside county apps, print) |
| `A-/B-lockup-endorsed-light/dark.svg` | "Swiftfleet by Swiftcent" |
| `app-icon.svg`, `symbol.svg`, `symbol-mono.svg`, `maskable-source.svg` | Icon and symbol |
| `kit/svg/` | Black, white, navy, square and favicon variants (wordmark variants from scheme B) |
| `kit/web/` | favicon.ico/svg, favicon-16/32/48, apple-touch-icon, icon-192/512, maskable-512, manifest, head snippet |
| `motion/index.html` | Logo, splash and dispatch animation using scheme B |
